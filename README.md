# 🌧️ Игра «Дождь мыслей» (Rain of Thoughts)

Сюжетная инди-игра головоломка на Unity с глубоким нарративом, метафорическими уровнями и комиксной визуализацией.

## 🛠️ Структура проекта

- **`Assets/Scripts/`** — Скрипты игровой логики (`GridSpawner.cs`, `StoryDataLoader.cs`, `UIManager.cs` и др.)
- **`Assets/Voiceover/`** — Аудиофайлы озвучки реплик Марты (.m4a)
- **`Assets/Sounds/`** — Звуковые эффекты (SFX) игры
- **`Assets/Music/`** — Музыкальные темы и дорожки
- **`Assets/Videos/`** — Анимированные видеофрагменты и фоновые вставки
- **`Assets/TextMesh Pro/`** — Ассеты шрифтов и стилей текста
- **`ProjectSettings/`** — Настройки проекта Unity
- **`Packages/`** — Манифест пакетов Unity Package Manager
