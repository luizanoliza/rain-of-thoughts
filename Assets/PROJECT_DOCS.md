# Документация проекта

Unity 2022.3.45f1, 2D. Документ составлен при передаче проекта. Покрывает архитектуру, назначение скриптов, структуру данных и известные проблемы.

---

### Обзор архитектуры

Игра построена вокруг **главы → уровни → триггеры**: текстовый файл `story.txt` описывает главы и слова-триггеры, `GridSpawner` спавнит их падающими элементами, игрок кликает по правильным, между уровнями иногда показывается картинка-награда в зависимости от того, как прошёл уровень.

Четыре крупных подсистемы:

- Геймплей-цикл - `GridSpawner` (центральный дирижёр: спавн, клики, счёт, переход между уровнями/главами) + `PrefabItem` (один падающий элемент) + `StoryDataLoader` (парсер `story.txt`).
- Прогресс/награды - `ImagePopupManager` (показ картинки между уровнями) + `ImageSpawner` (галерея открытых/закрытых картинок).
- UI главы - `UiChapterManager` (цвета, текст, фейды при смене главы), синхронизируется с `GridSpawner`.
- Меню и звук - `UIManager`, `MenuAudioSettings`, `GameAudioManager`, `MusicPlayer` + мелкие UI-эффекты.

# Как это связано в рантайме (упрощённо)

1. Сцена меню: `UIManager` показывает демо-панель, `MenuAudioSettings` подтягивает громкости из `PlayerPrefs` в слайдеры. Кнопка "играть" → `UIManager.OpenGameScene()` грузит сцену игры (индекс `1`).
2. Сцена игры: `GridSpawner.Start()` → `StoryDataLoader.LoadTextFile("story.txt")` → парсит главы и триггеры → загружает главу 0 → спавнит первые ряды из `prefabsChapterN` через `PrefabItem`.
3. Клик по элементу → `PrefabItem.OnImageClicked()` → `GridSpawner.RegisterClick()` → засчитывает клик, решает "правильный/неправильный" ответ (в т.ч. если триггер из **более ранней** главы и ещё не отработан - считается неправильным), пересчитывает мультипликатор скорости.
4. Уровень заканчивается по лимиту кликов или когда `speedSlider` доходит до нуля → `EndLevelSequence()` → считает результат уровня ("Хорошее"/"Нейтральное"/"Плохое" - пороги свои для каждой главы) → возможно показывает картинку через `ImagePopupManager` (интервал показа настраивается) → переходит к следующему уровню/главе.
5. `UiChapterManager` каждые 0.5 сек проверяет текущую главу `GridSpawner` и анимированно переключает цвета/текст/UI главы.
6. `GameAudioManager` в сцене игры применяет сохранённые в `PlayerPrefs` громкости.

# 2. Что делает каждый скрипт (кратко)

# Геймплей и данные
| Скрипт | Назначение |
|---|---|
| `GridSpawner.cs` | Центральный контроллер уровня: спавн триггеров, обработка кликов, скорость падения, слайдер времени, переход между уровнями/главами, запуск показа картинок, screenshake при ошибке. |
| `PrefabItem.cs` | Поведение одного падающего элемента: движение вниз, обработка клика, передача события в `GridSpawner`. |
| `StoryDataLoader.cs` | Статический парсер `story.txt` - превращает текст в список глав с триггерами (правильные/неправильные варианты ответа). |

# Прогресс и картинки-награды
| Скрипт | Назначение |
|---|---|
| `ImagePopupManager.cs` | Показывает картинку между уровнями в зависимости от типа прохождения ("Хорошее"/"Нейтральное"/"Плохое"), с анимацией и сохранением прогресса показа в `PlayerPrefs`. |
| `ImageSpawner.cs` | Строит "галерею": спавнит слоты для всех картинок главы, показывая реальные для уже открытых и заглушку для остальных. |

# UI и меню
| Скрипт | Назначение |
|---|---|
| `UIManager.cs` | Управляет панелями меню (настройки, титры, демо-подсказка, список сюжетов), выходом из игры и полным сбросом прогресса. |
| `UiChapterManager.cs` | Анимированный переход UI/цветов/текста при смене главы, синхронизируется с `GridSpawner`. |
| `MenuAudioSettings.cs` | Слайдеры громкости в меню (музыка меню/игры/SFX), сохраняет в `PlayerPrefs`. |
| `GameAudioManager.cs` | Применяет сохранённые уровни громкости к аудиоисточникам игровой сцены. |
| `MusicPlayer.cs` | Синглтон с `DontDestroyOnLoad` для объекта фоновой музыки. Логики воспроизведения в самом скрипте нет - только персистентность объекта между сценами. |
| `TMPLinkOpener.cs` (класс `TMPClickableLink`) | Делает часть TMP-текста кликабельной ссылкой, открывает URL. |
| `ButtonHoverEffect.cs` | Анимация увеличения/смещения кнопки при наведении курсора. |
| `RotateToAngleOnHover.cs` (класс `UIRotateOnHover`) | Поворот элемента при наведении + звук клика + переход в сцену меню (индекс `0`) по клику. |
| `CustomScroll.cs` | Кастомный скролл списка (мышь/драг) с инерцией и лимитами позиции. |
| `RotateZ.cs` | Декоративный элемент: вращение + движение между двумя точками + случайные прыжки. |

# 3. Структура данных проекта

`Resources/Images/{Good|Neutral|Bad}/`
Спрайты с именами `1`, `2`, `3`... (без ведущих нулей). Порядковый номер = порядок показа. Пути к папкам настраиваются в инспекторе `ImagePopupManager` и `ImageSpawner` - **должны совпадать** между этими двумя компонентами.

`story.txt`
Ищется в следующем порядке: прямой путь → `Resources` (как `TextAsset`, без расширения) → `StreamingAssets/story.txt`. Формат:

```
[Chapter="0" Amount=5]
{
	Name = ""
	T = ""
	Ts1 = ""
	Ts2 = ""
	F = ""
}
```
`Amount` - количество уровней в главе. Триггеры без явных `Ts1/Ts2/F/Fs1/Fs2` используют `T`/`Name` как единственный вариант ответа.

# Ключи `PlayerPrefs`
| Ключ | Кто использует | Назначение |
|---|---|---|
| `GoodImagesShown`, `NeutralImagesShown`, `BadImagesShown` | `ImagePopupManager`, `ImageSpawner` | Сколько картинок каждого типа уже показано игроку. |
| `Volume_MenuMusic` | `MenuAudioSettings` | Громкость музыки в меню. |
| `Volume_GameMusic` | `MenuAudioSettings`, `GameAudioManager` | Громкость музыки в игровой сцене. |
| `Volume_SFX` | `MenuAudioSettings`, `GameAudioManager`, `GridSpawner`, `UIRotateOnHover` | Громкость звуковых эффектов. |
| `DontShowDemo` | `UIManager` | Не показывать демо-подсказку повторно. |

`UIManager.ResetEVERYTHING()` вызывает `PlayerPrefs.DeleteAll()` - сбрасывает вообще всё.

# 4. Известные проблемы / технический долг

Ничего из этого не блокирует игру, но стоит знать при дальнейшей работе:

- **`GridSpawner` - God Object.** Спавн, парсинг истории, аудио, screenshake, слайдер, показ картинок и переходы между главами - всё в одном классе (1000+ строк). Стоит постепенно разносить по отдельным компонентам.
- **Reflection в `GridSpawner.SpeedApplier`.** При каждом спавне элемента сканирует все `MonoBehaviour` в поисках полей `speed`/`fallSpeed` через reflection и пишет туда значение. При этом `PrefabItem` и так сам считает скорость напрямую - система немного избыточна. Перед удалением стоит убедиться, что на неё ничего не завязано.
- **Reflection в `UiChapterManager`.** Читает приватное поле `GridSpawner.currentChapterIndex` каждые 0.5 сек вместо публичного свойства/события. Лучше добавить `public int CurrentChapterIndex => currentChapterIndex;` или событие `OnChapterChanged`. Сделано пока что так для упрощения.
- **Магические строки** `"Хорошее"/"Нейтральное"/"Плохое"` продублированы в трёх скриптах без общего `enum`. Опечатка в любом месте сломает логику молча, без ошибки компиляции. Стоит поменять.
- **Дублирование ключей `PlayerPrefs`** - константы объявлены отдельно в `ImagePopupManager` и `ImageSpawner`, нет единого источника правды, но работает пока что.
- **Пороги "хорошо/нейтрально/плохо" по главам** зашиты хардкодом в `GridSpawner.GetChapterPerformance()` (switch по номеру главы). Стоит вынести в `ScriptableObject` или сам `story.txt`, чтобы геймдизайнер мог их менять без правки кода. Не было реализовано за отсуствием надобности, но надо бы сделать.
- **Кросс-глава триггеры - подтверждено намеренное поведение.** `GridSpawner.ChooseRandomTrigger()` выбирает триггеры из **всех** глав, а не только текущей (включая ещё не пройденные) - это осознанное решение геймдиза, трогать не нужно.

# 5. Как запустить проект

1. Открыть проект в Unity **2022.3.45f1**.
2. Сцена меню (build index `0`) и сцена игры (build index `1`) должны быть добавлены в Build Settings в этом порядке.
3. В инспекторе `GridSpawner` нужно вручную назначить: `parentRect`, префабы по главам (`prefabsChapter0..4`), UI-ссылки (`countersText`, `remainingClicksText`, `responseText`, `speedSlider`), `imagePopupManager`.
4. `story.txt` положить в `Resources` (как `TextAsset`, без расширения в имени поля) либо в `StreamingAssets`.
5. Картинки-награды - в `Resources/Images/Good`, `Resources/Images/Neutral`, `Resources/Images/Bad`, с именами `1`, `2`, `3`...
6. Для чистого теста прогресса - `PlayerPrefs.DeleteAll()` (например, через кнопку сброса в `UIManager`) перед первым запуском.
